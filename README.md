# 하늘길 항공사 ✈️

혼자서 1963·1983·2003·2026년 가운데 한 해에 시작해 세계 57개 도시에 지점을 내고, 실제 기종의 비행기를 주문·리스·중고로 들여 노선을 열고, 그 해에 날던 실제 항공사 수십 곳(컴퓨터)과 겨루며 길게는 2100년까지 한 달씩 회사를 키우는 항공사 경영 게임입니다.

브라우저 하나로 하는 혼자용 게임이고, 서버나 인터넷 연결 없이 동작합니다.

## 게임 소개

- **세계 항공사와 겨루기**: 사람은 한 명이고, 시작한 해에 날던 실제 항공사가 **모두** 컴퓨터 라이벌로 나와요 (1983년 41곳, 2026년 41곳). 세월이 흐르면 실제 역사대로 그 달에 새 항공사가 생기고(1985년 10월 에미레이트, 1988년 12월 아시아나…), 이름이 바뀌고(BOAC → 영국항공, 에어랑카 → 스리랑카항공), 합쳐지고(TWA → 아메리칸, 노스웨스트 → 델타, 2024년 아시아나 → 대한항공·하와이안 → 알래스카항공), 사라져요(팬암 1991, 스위스에어 2001 — 뒤를 이은 스위스국제항공은 2002년에 새 회사로 생겨요). 실제 역사는 보통 판의 시장 변화와 같은 표(`airlineHistory.ts`)를 써요. 컴퓨터 회사는 본거지 크기에 맞는 규모까지만 자라고, 돈이 모자라면 한 번은 구조 조정으로 살아나요. 표·그래프·지도 범례에는 회사 가치 위쪽 여덟 곳과 내 회사가 보이고, 지도는 처음에 내 노선만 보여 줘요 (`world.ts`)
- **2100년까지, 예측한 미래**: 게임 길이는 10·20·30·50년 또는 ‘2100년까지’. 2027년부터는 **예측해서 지어낸** 미래 기종 33종과 화물기 6종(오픈팬 A250·버팀 날개 797, 새 초음속기 오버추어, 가오리 모양 JetZero Z4·Z7, 수소 ZEROe·전기 ES-90, 중국 C929·C939, 한국 KAI·인도 HAL·Tata의 새 기종, 극초음속 HX-1, 900석 A500 …)과 미래 항공사 14곳(바라트항공·부산퍼시픽항공·아프리카유니언항공·H2유럽항공·오로라초음속항공 …), 미래의 합병이 이어져요. 도시는 2030년 뒤에도 지역마다 다른 빠르기로 자라고(아프리카·남아시아가 가장 빠르게) 공항도 커져요. 회사 이름이 실제 회사와 같아도 2027년 뒤의 기종·해·성능·사건은 모두 상상한 게임 속 이야기예요

- **저장**: 하던 게임은 브라우저의 큰 저장소(IndexedDB)에 저절로 저장돼 5MB 한도 없이 이어 할 수 있어요 (예전 localStorage 저장은 읽으면서 옮겨요). 설정 화면과 게임 화면의 ‘💾 파일로 내려받기’로 내 컴퓨터에 저장 파일(.json)을 보관하고, ‘📂 저장 파일 불러오기’로 다른 컴퓨터·브라우저에서도 이어 해요 (`saveDb.ts`)
- **실제 항공사 맡기 / 새 항공사 만들기**: 그 해에 날던 실제 항공사 52곳(대한항공·아시아나·팬암·루프트한자·아에로플로트 등) 가운데 하나를 맡아 그 본거지에서 시작하거나, 내가 이름을 지은 새 항공사로 실제 항공사들과 겨뤄요. 실제 회사의 이름·IATA 부호·칠 색만 빌리고 로고는 쓰지 않아요
- **기종 그림**: 실제 기종 59종과 예측한 미래 기종 33종 모두 실제 길이·날개폭·동체 지름·후퇴각·엔진 자리로 3D 모형을 만들어 비스듬히 위에서 본 SVG로 그려요 (747 2층 혹, A380 2층, 콩코드 삼각 날개, 꼬리 엔진·T자 꼬리·프로펠러·윙렛). 주문 화면은 흰 몸통에 파란 줄, 내 비행기는 회사 색과 꼬리 무늬
- **사진**: 도시 56·항공사 51장, 위키미디어 공용의 자유 라이선스 사진 (게임 안 ‘📷 사진 출처’에 지은이·라이선스·원본 링크)
- **공항 도면**: 지도에서 도시를 누르면 정보 칸에 그 해의 대표 공항을 위에서 본 모습이 나와요. 오픈스트리트맵의 실제 활주로·유도로·계류장·터미널·격납고·관제탑·주기장·바닷가를 그대로 줄여 그린 SVG예요 (활주로 번호·문턱 줄무늬·가운데 선까지). 누르면 큰 창에서 휠·끌기·`+` `−` `0`으로 확대해 보고, 활주로 이름과 길이·문 연 해·게임 속 공항 등급·내 슬롯을 함께 보여 줘요. 그 도시를 드나드는 회사 비행기는 실제 치수로 그린 기종 그림이 회사 색으로 주기장에 서고(회사를 누르면 그 회사만 또렷하게), 남은 자리엔 그 시대 기종의 다른 항공사 비행기(회색)가 서며, 활주로에선 번갈아 뜨고 내려요 (속도 ‘아주 빠르게’나 컴퓨터의 ‘동작 줄이기’ 설정이면 멈춰요). 공항은 시대에 따라 바뀌어요 — 서울 김포→인천(2001), 홍콩 카이탁→첵랍콕(1998), 도쿄 하네다→나리타(1978)→하네다(2010), 오사카 이타미→간사이(1994), 몬트리올 미라벨(1975~1997) 등 18개 도시. 문 닫은 카이탁·엘리니콘은 남은 땅 모양과 옛 지도로 어림해 그렸어요. 공항이 여럿인 도시는 탭으로 골라 봐요 — 그 해에 손님을 받던 공항만 나오고 대표 공항이 먼저예요 (런던 히스로·개트윅·스탠스테드·루턴·시티, 뉴욕 JFK·라과디아·뉴어크, 모스크바 셰레메티예보·브누코보·도모데도보, 서울 2001년부터 인천·김포 등 25개 도시, 공항 93곳). 게임에서는 도시를 공항 하나로 셈하므로 회사 비행기는 대표 공항에 서고, 함께 쓰는 공항엔 다른 항공사 비행기만 서요. 지도 데이터 © OpenStreetMap 기여자(ODbL), `scripts/fetch-airport-maps.py`로 다시 받을 수 있어요
- **운항 관제실 화면**: 짙은 남색 바탕에 밤의 레이더 같은 세계 지도, 공항 출발 안내판처럼 갈라진 글자판에 뜨는 날짜·현금, 불이 켜지는 탭과 고르기 단추, 노란 안내판 색의 '이번 달 마치기'. 컴퓨터의 밝은/어두운 설정과 상관없이 늘 이 화면이에요 (`src/games/airline/theme.css`)
- **도시마다 특색**: 시대에 따라 바뀌는 크기, 공항 등급(내릴 수 있는 기종·운항 횟수), 사업·관광 손님 비율, 성수기, 이용료
- **경영**: 지점·노선(정해진 한도 없이 공항 슬롯·돈·비행기만큼), 한 비행기가 주 98시간 안에서 여러 노선 운항, 운임 ±30%, 대출
- **한 달씩 진행**: '이번 달 마치기'마다 달 결산 요약, 분기 끝에 결산, 해 끝에 연간 보고서. 계절 수요는 열두 달(성수기·연휴), 유가는 달마다 오르내림. '분기 끝까지 맡기기'·'일이 생길 때까지' 자동 진행
- **연료 탱크**: 작은 탱크(2,000톤)부터 대형 연료 기지(18만 톤)까지 지어 두고, 유가가 쌀 때 사 두면 비행기가 탱크 연료를 산 값 그대로 먼저 써요. 유가 그래프에 '보통 값'과 사 둔 값이 함께 보이고, '보통 값보다 쌀 때' 같은 자동 사기도 있어요 (석유 파동 전에 채워 두면 크게 아껴요)
- **기체 상태와 C점검**: 비행기마다 상태(%)가 있어 날수록 닳고(오래되거나 정비를 아끼면 더 빨리), 낮으면 고장·지연·결항이 잦고 평판과 되팔 값이 떨어져요. 점검 시점(늦게 35%·보통 50%·일찍 65%) 아래로 내려가면 그달은 정비고에서 C점검을 받아요 — 쉬는 비행기가 있으면 대신 날아요. 점검하면 새 비행기는 97%로 돌아오지만 낡을수록 덜 돌아와요. 한 대씩 보내거나 미룰 수도 있어요
- **공항 시설**: 지점 공항에 🛋️ 라운지(그 도시 사업 손님 +6%·환승 사업 손님 +10%·평판), 🛠️ 정비 기지(C점검 −35%·정비고 자리 +2·덜 닳음), 🏛️ 전용 터미널(큰 공항 슬롯 +25%·덜 붐빔·갈아타는 시간 단축)을 지어요. 유지비는 지점·시설 유지비로
- **연말 시상식**: 해마다 12월 결산에 🏆 올해의 항공사·⏱️ 정시 운항상·🍽️ 서비스상·📈 성장상·🔁 환승 허브상을 줘요. 부문마다 넘어야 하는 문턱이 있고, 받으면 평판이 오르며 올해의 항공사는 한 해 동안 손님이 3% 늘어요. 재무 화면에 트로피 진열장
- **업적과 명예의 전당**: 사람 회사가 이루는 배지 38개(동 10·은 19·금 9, 숨은 업적 셋 — 첫 하늘길·넓은 동체부터 기름값 폭풍 속 흑자·저가항공 우승·회사 합치기·시상식 싹쓸이·세 시대 정복·도전 과제 완주까지)가 이 컴퓨터에 판을 넘어 쌓이고, 처음 이룬 회사 이름이 남아요. 이루면 달 결산 뒤 작은 알림이 한꺼번에 떠요. 끝까지 마친 게임은 최종 회사 가치 상위 10개(회사·시작 해·기간·방식·사업 모델·날짜)와 모든 게임 기록(가장 큰 비행기 무리·한 해 가장 많은 손님·한 해 가장 큰 이익·한 게임 트로피·가장 긴 노선망 …)에 올라요. 설정 화면 ‘🏛️ 명예의 전당 · 업적’, 재무 화면 트로피 진열장 아래 배지 줄, 결과 화면에 새 업적과 순위
- **전세기 계약**: 비행기 화면 '전세기 의뢰' 게시판에 한 달짜리 연속 전세(수학여행 단체·여행사 휴가철 전세·교민 귀국·올림픽 선수단 …)가 올라와요. 먼저 맡은 회사가 쉬는 비행기로 손님 수천 명을 여러 번에 나눠 데려갔다 데려오고, 너무 큰 비행기는 빈 좌석에 연료를 태워요
- **운항 현장**: 지연·결항·회항·점검 정지 (기체 나이, 정비 수준, 공항 혼잡, 일손, 태풍·폭설·몬순·안개). 정비 수준·예비기·예비 승무원으로 대비하고, 정시 운항률이 평판과 손님에 영향 (사고·부상은 없음)
- **직원과 조직**: 조종사·객실 승무원·정비사·지상직을 뽑아야 비행기가 뜸(1~5달). 모자라면 초과 근무나 결항, 임금·초과 근무·성장으로 움직이는 조직 만족도가 너무 낮으면 파업. 훈련원
- **운항 시간표**: 노선마다 아침·낮·저녁·밤 편수, 사업 손님은 아침·저녁·관광 손님은 낮, 큰 공항의 붐비는 시간대 슬롯과 밤 운항 금지 공항, 비행기마다 하루 운항표
- **보고서**: 달마다(이익·회사 가치·정시율·유가·계절 수요·노선별 작은 그래프·직원 수) / 분기 / 해마다 / 운항 상황판(이번 달 사건과 석 달 날씨 걱정)
- **좌석 배치·기내식**: 비행기마다 일등석·비즈니스석 수와 일반석 간격(29·31·34인치)을 정하면 좌석 배치도와 노선 이익 변화를 미리 보여 줘요. 고급 좌석은 사업 손님에게 비싸게 팔리고, 일반석이 촘촘하면 좌석이 늘어요. 기내식 5단계(음료만~셰프 코스)도 비행기마다
- **등급별 운임**: 노선마다 일등석·비즈니스석·일반석·화물 운임을 따로 ±30%. 고급 좌석을 찾는 손님은 사업 손님·먼 거리·나중 시대일수록 많고(1979년 전에는 비즈니스석 없이 일등석만), 너무 비싸면 아래 등급으로 내려가거나 라이벌에게 가요. 노선 창 ‘등급별 운임’ 카드에 등급마다 좌석·손님·탑승률·수입과 💡 추천 운임
- **사업 모델**: 회사마다 🛫 풀서비스 · 🎒 저가항공 · 📦 화물 전문 가운데 하나로 시작해요 (재무 화면에서 돈과 6달을 들여 바꾸기). 저가항공은 한 등급 촘촘한 좌석·싼 비용·빠른 회전·짐·좌석 값 부가 수입, 대신 갈아타기·제휴·짐칸 화물이 없고 1978년 규제 완화 뒤 관광 손님이 늘어요. 사람과 셋 넘게 겨루면 컴퓨터 하나가 가끔 지어낸 이름의 저가항공(1988년부터)이나 화물 전문이 돼요
- **화물**: 도시 경제·무역 도시·거리·시대에 따라 수요가 생기고 10~12월이 성수기, 유가가 비싸면 줄어요. 넓은 동체 여객기는 짐칸에 화물을 많이 싣고, 실제 화물기 14종(DC-8F부터 747-8F·777F까지, 수치는 근삿값)은 창문 없는 그림으로. 손익표·달 결산에 화물·부가 수입·고급 좌석 수입이 따로 보여요
- **광고와 캠페인**: 지역마다 광고비와 매체(TV·신문·여행 잡지·라디오·인터넷), 석 달에 하나 캠페인(할인 대잔치·마일리지 두 배·경품 행사·스타 광고 모델)
- **단골 손님과 브랜드**: 1981년부터 재무 화면 ‘단골 손님과 브랜드’에서 ‘하늘길 단골 손님’ 프로그램을 시작해 💳 기본(적립) → 🥈 실버(좌석 승급) → 🥇 골드(라운지 초대)로 키워요. 회원은 지역마다 몇 달에 걸쳐 모이고(광고로 알려진 지역·좋은 평판·‘마일리지 두 배’ 캠페인·프로그램이 있는 동맹 회사면 더 빨리), 우리 비행기를 더 고르며(사업 손님은 더) 운임이 조금 비싸도 덜 떠나요. 대신 단계 값·달 운영비·마일리지 값이 들고, 늦는 비행이 잦거나 평판이 나쁘거나 그 지역 노선을 줄이면 떠나요 — 다른 회사와 겨루는 노선이 많을수록 이득이고 혼자 나는 작은 회사가 골드를 하면 손해예요. 브랜드는 ⏱️ 믿음직한 정시·🍽️ 따뜻한 서비스·🏷️ 알뜰한 운임·🌐 넓은 노선망 가운데 하나를 내세우고, 실제 숫자(정시율·기내식·운임·노선망…)가 어울리면 브랜드 힘(0~100)이 쌓여 맞는 손님이 조금 더 와요 (바꾸려면 돈과 석 달, 맞는 연말 상을 받으면 쑥). 카드에 회원 그래프·지역 막대·어울림 막대와 까닭
- **부대사업 8가지**: 호텔·여행사·공항버스·레스토랑·백화점·리조트·스키장·놀이공원 (도시에 맞는 것만, 계절마다 수입이 달라요)
- **실제 역사**(켜고 끌 수 있어요): 냉전과 국교 때문에 막힌 하늘길(미·중 1979, 한·중 1992, 한·소 1990 등)과 소련·서방 비행기 구매 제한, 석유 파동·걸프 전쟁·9·11·사스·금융 위기·코로나19 같은 사건
- **새 노선 취항**: 지도에서 노선이 그려지며 첫 비행기가 날아가고, 내 회사면 축하 카드가 떠요
- **오케스트라풍 음악**: 금관 팡파르·현악·하프·팀파니·심벌과 홀 잔향을 WebAudio로 합성. 설정 화면 '하늘길 서곡', 경영 화면 '창공의 항로'(호른 → 트럼펫 → 오보에 → 고조 → 한 음 올린 절정), 분기 결산(흑자·적자)과 게임 끝(우승·마무리) 팡파르 — 팡파르가 나오는 동안 배경음악은 쉬었다가 다음 마디부터 이어져요. 새 노선 취항 팡파르는 축하 카드의 비행기가 내릴 때 '빠-밤!' 하고(가까운 노선은 짧게, 5,000km 넘는 노선은 웅장하게), 배경음악은 작게 깔려요
- **환승과 항공 동맹**: 본사(허브)에서 갈아타는 손님. 서너 회사 가운데 셋까지 모이는 항공 동맹(하늘별·푸른띠 동맹 …)을 만들거나 초대·가입하면 동맹 회사들의 노선망으로 이어 태우고, 동맹 회사도 지점이 있는 도시 손님 +5%, 동맹 마일리지(회사 하나마다 +1.5%), 동맹 라운지 함께 쓰기. 저가항공은 동맹에 들지 않아요
- **비행기**: 실제 기종 60종(707부터 777-9까지, 소련제 8종 포함, 수치는 근삿값)과 상상 속 미래 기종 3종. 새 비행기는 주문하면 3~12달 뒤 인도(처음 2년 할인), 리스는 바로, 중고 시장, 같은 계열이 많으면 정비비 할인
- **주식과 인수합병**: 회사마다 주가(시가 총액의 1%, 한 해 이익에 따라 ×0.6~2)가 있어 다른 회사 주식을 사고팔고, 흑자 분기마다 이익의 20%를 주주 회사에 배당해요. 남들이 가질 수 있는 몫은 70%까지, 증자는 한 해에 한 번. 컴퓨터 회사는 51% 넘게 가지면 남은 주식을 사들여 노선·비행기·직원·빚째 합칠 수 있어요 (사람 회사는 인수할 수 없고 49%까지만). 치열한 컴퓨터는 다섯 해 뒤 아주 작거나 돈이 바닥난 컴퓨터 회사를 사들이고, 시장 변화를 켠 판이면 보통 컴퓨터도 여섯 해 뒤 회사가 넷 넘게 날 때 두 달 넘게 돈이 모자라거나 아주 작고 적자인 회사를 사들여요
- **운수권과 항공 협정**(설정): 나라와 나라를 잇는 노선은 두 나라 협정이 정한 주간 왕복 안에서 날아요(그 두 나라 사이 우리 노선을 모두 더해서, 나라 안 노선은 자유). 옛 항공 협정(~1977) → 넓힌 항공 협정(1978~) → 하늘 개방 협정(나라마다 1995~2020년 무렵, 유럽 나라끼리는 1997년, 제한 없음). 간단히: 1978년부터 본국 노선은 자유, 외국과 외국 사이는 주 21회. 실제처럼: 외국과 외국 사이는 신청해야만 날고, 옛 협정 동안은 두 나라 사이 항공사 수도 정해져요. 신청하면 몇 달 뒤 결산 때 정해지고(평판·본국 노선이면 잘 돼요), 더 받은 횟수는 1년 동안 안 쓰면 돌려줘요. 냉전·국교로 막힌 하늘길은 운수권으로도 못 열고, 동맹 회사 비행은 우리 횟수에 들지 않으며 전세기는 운수권을 쓰지 않아요. 인수하면 그 회사 운수권도 넘겨받아요. 노선 화면에 남은 주간 횟수와 신청 버튼, 재무 화면 운수권 카드 (협정 이름·해는 게임용 어림)
- **한꺼번에 고치기**: 노선 화면 '🧰 한꺼번에 고치기'에서 모든 노선의 운임(등급·화물까지)·시간표를 이익이 가장 큰 쪽으로, 열여덟 해 넘은 비행기를 더 버는 새 비행기로 한 번에 — 살펴보기로 몇 개를 고치고 이익이 얼마나 느는지 먼저 보여 줘요
- **낡은 비행기 바꾸기**: 비행기 화면 맨 위 ‘바꿀 비행기’ 카드에 낡은(18년+)·닳은·단종·교체 주문 비행기 수가 보이고, 누르면 그 비행기만 걸러 봐요 (나이·상태·가동률 순으로 줄 세우기도). ‘비서에게 바꿀 계획 세우기’를 누르면 급한 비행기(닳았거나 25년 넘음)는 리스로 바로(한 달 3대까지), 돈이 넉넉하면 새 비행기를 주문해 두고, 쉬는 낡은 비행기는 예비기로 세지 않고 파는 계획을 세워요 (예비기는 젊은 내 비행기로만 둬요) — 골라서 한 번에 적용해요. 비행기마다 ‘♻️ 바꾸기’로 리스와 주문을 견주어 고를 수도 있어요. 주문한 비행기가 오면 낡은 비행기의 노선을 그대로 넘겨받고 낡은 비행기는 팔아요
- **결정할 일**: 서너 분기마다 노조 협상·연료 헤지·슬롯 경매·올림픽 입찰 같은 18가지 상황에서 결과를 미리 보고 고르기
- **경쟁**: 라이벌이 내 노선에 들어오거나 운임 전쟁을 걸면 소식, 운항을 멈춘 회사의 비행기는 중고 시장으로, 슬롯은 다시 비어요
- **시장 변화**(설정, 기본 켜기 · 자리 넷으로 하는 보통 판, 세계 항공사 모드는 위처럼 따로): 경쟁 항공사가 실제처럼 새로 생기고, 문을 닫고, 인수돼요. 동시에 6곳까지 날아요(문을 닫은 회사도 기록으로 남아 한 판에 12곳까지). 문을 닫은 회사가 남긴 빈자리는 반년쯤 지나면 새 회사가 노리고, 장사가 잘되는 시절(1978년 규제 완화 뒤·저가항공 붐)에도 가끔 새 회사(🆕 새 항공사·🎒 저가항공·📦 화물 전문, 실제 항공사 모드면 그동안 다른 하늘에서 날던 실제 항공사)가 생겨요 — 하늘이 붐빌수록 덜 생기고, 시작 두 해 동안은 생기지 않아요. 돈이 4달 내내 모자란 컴퓨터 회사는 ① 돈이 넉넉한 사람 회사에 인수 제안(결정할 일: 값과 넘겨받는 노선·비행기·빚을 보고 정해요) ② 다른 컴퓨터가 싸게 인수 ③ ⚖️ 법정 관리(빚을 줄이고 손해 노선·쉬는 비행기 정리, 한 회사에 한 번) ④ 운항 중단 순서로 정해져요. 새로 생긴 회사는 4년 동안 컴퓨터가 주식으로 사들이지 않고, 회사를 합친 컴퓨터는 3년 동안 다른 회사를 사냥하지 않아요. 저가항공을 합친 풀서비스 회사는 빠른 회전으로 짠 운항 횟수를 줄이고, 사업 모델에 맞지 않는 기종은 쉬게 해요. 실제 항공사·실제 역사를 켠 판에서는 실제 항공사가 그 해 무렵 역사를 만나요: 18달 전부터 손님이 줄고 비용이 늘다가(🌧️ 먹구름), 그 달에 돈이 모자라거나 적자면 역사대로 문을 닫거나(팬암 1991·스위스에어 2001·바리그 2006·알리탈리아 2021) 합쳐지고(TWA → 아메리칸 2001·노스웨스트 → 델타 2010·아시아나 → 대한항공 2024·하와이안 → 알래스카항공 2024; 합칠 회사가 사람 회사면 인수 제안, 판에 없으면 판 밖으로), 튼튼하면 💪 살아남아 역사와 다른 길을 가요. 이름도 바뀌고(BOAC → 영국항공 1974·에어랑카 → 스리랑카항공 1999·란칠레 → 라탐 2016), 그 해에 생긴 실제 항공사(대한항공 1969·싱가포르항공 1972·에미레이트 1985·아시아나 1988·카타르 1994·스위스국제항공 2002 …)는 자리가 있으면 들어오고 없으면 🌍 세계 소식만 나와요. 사람이 고른 회사는 역사에 끌려가지 않고(소식만), 컴퓨터에게 인수되지도 않아요. 뉴스 화면 ‘업계 소식’ 카드에 지금 나는 회사 수, 눈여겨볼 회사(먹구름·법정 관리·돈 걱정·새 회사)와 업계 연표, 보고서 그래프는 새 회사를 생긴 달부터 그려요 (해와 경영은 게임용 어림, `src/games/airline/industry.ts`)
- **라이벌 경영진 성격과 관계**(설정, 기본 켜기): 컴퓨터 회사마다 경영진 성격이 하나씩 있어요 — 🐯 공격적인 확장가(돈이 넉넉하면 노선을 더 빨리 늘리고 붐비는 노선에도 들어와요)·🐿️ 알뜰한 살림꾼(돈을 넉넉히 남기고 중고 비행기, 휴전을 좋아해요)·두루미 서비스 장인(기내식 한 단계 위·새 비행기만·운임 높게)·🦉 허브 전략가(본사 노선 먼저·큰 비행기·동맹 좋아함)·🦊 운임 승부사(같은 노선 라이벌보다 5%p 싸게)·알바트로스 새 길 개척자(라이벌 없는 노선·먼 노선). 사람 이름 없이 직접 그린 동물 그림과 성격 이름만 쓰고, 실제 항공사 이름이어도 게임 속 이야기예요. 컴퓨터 성향(느긋·보통·치열)은 그대로 '얼마나 세게'를 정해요. 컴퓨터마다 우리 회사와의 사이(−100~+100: 단짝·사이좋음·보통·껄끄러움·불꽃 라이벌)가 있어 그 회사 노선에 들어가기·10%p 넘게 싸게 팔기·주식 사기로 나빠지고 같은 동맹·휴전 지키기·인사 방문·시상식으로 좋아져요(달마다 조금씩 보통으로). 사이가 좋으면 동맹 제안을 잘 받아 주고 우리 노선을 피하며 먼저 휴전을 청하고, 아주 나쁘면 우리 노선에 일부러 들어오거나(확장가) 더 싸게 팔아요(운임 승부사). 뉴스 화면 ‘라이벌 경영진’ 카드에서 🎁 인사 방문(회사 가치의 0.4%, 여섯 달에 한 번)·🕊️ 노선 휴전(여섯 달 동안 두 회사 모두 그 노선 일반석 운임을 내리지 않기, 성격과 사이에 따라 받아들여요)·🤝 동맹 제안을 하고, 사이가 바뀌면 짧고 다정한 한마디 소식이 와요
- **경영 비서와 목표**: 지난 분기 숫자로 할 만한 일을 골라 ‘적용’ 한 번으로 (‘더 보기’로 10개까지). 할 일이 여럿이면 체크해서 고른 것을 ‘한꺼번에 하기’로 차례로 하고, 못 한 것은 까닭을 알려 줘요. 낡은 비행기·쉬는 낡은 비행기·많이 닳은 비행기는 여러 대를 한 줄로 묶어 권해요. 해마다 목표 3개와 경영 평가(S~D)
- **역사 시나리오**(설정 ‘게임 방식’): 제트기 시대(1963 도쿄)·점보기와 허브(1970 암스테르담)·석유 파동(1973 마드리드)·미국 규제 완화(1978 샌프란시스코 저가항공)·화물 붐(1985 홍콩 화물 전문)·하늘 개방 협정(1996 싱가포르)·저가항공 붐(2003 바르셀로나) 일곱 시대에 정해진 회사(돈·빚·실제 기종 비행기와 노선·사업 모델)와 라이벌로 시작해 단계 목표 셋을 차례로 이뤄요. 시대마다 운수권·실제 역사·컴퓨터 성향이 정해져 있고, 오른쪽 목표 칸에 단계와 목표마다 막대, 단계를 이루면 이야기 창이 떠요. 해내면 ★, 정해진 때까지 빨리 하면 ★, 덤 목표까지 하면 ★ (3개까지). 시나리오마다 가장 좋은 기록(별·걸린 달)이 이 컴퓨터에 남고, 업적 ‘역사 속으로’·‘하늘길 역사가’가 있어요 (회사와 이야기는 지어낸 것, 라이벌의 실제 항공사 경영도 게임 속 이야기)
- **이기는 방법**: 정해진 해까지 회사 가치 1등 / 지역+가치 목표 먼저 / 도전 과제 8가지. 컴퓨터 성향 느긋·보통·치열
- 조작: 화면 `1`~`7`(지도·비행기·노선·재무·인사·보고서·뉴스), 이번 달 마치기 `Enter`, 닫기 `Esc`, 지도 `+` `−` `0`

## 자동 빌드와 배포

`.github/workflows/build.yml`이 push할 때마다 실행됩니다.

1. **모든 브랜치·PR**: 타입 검사 → 테스트 → 빌드 → zip을 Actions 아티팩트로 보관
2. **기본 브랜치에 push**:
   - [Releases](https://github.com/lengbong/SkyRoad/releases)의 `최신 빌드`(태그 `latest`)를 새 zip으로 교체
   - GitHub Pages에 배포
3. **`v*` 태그 push** (예: `v1.0.0`): 그 버전의 릴리스를 따로 만들어 보관

> Pages 배포는 저장소 **Settings → Pages → Source**가 **GitHub Actions**로 되어 있어야 동작합니다.

## 개발

Node.js 22 이상이 필요합니다.

```bash
npm install
```

```bash
npm run dev        # 개발 서버 (http://localhost:5173)
```

```bash
npm test           # 규칙·컴퓨터 회사 테스트
```

```bash
npm run build      # dist/index.html 한 파일로 빌드
```

빌드 결과는 JS·CSS·사진이 모두 들어간 `dist/index.html` 한 파일이라서 `file://`로 열어도 실행됩니다.
