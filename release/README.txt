하늘길 항공사
==============

[실행 방법]
1. 이 폴더의 index.html 파일을 더블클릭하세요.
2. 크롬, 엣지, 웨일, 파이어폭스 같은 브라우저에서 바로 열려요.
3. 인터넷 연결 없이도 실행돼요.

[게임 방법]
- 혼자 하는 항공사 경영 게임이에요. 그 해에 날던 실제 항공사 수십 곳은 컴퓨터가 맡아요.
- 실제 항공사(로고 없음)나 지어낸 이름으로 시작해요.
- 지도에서 도시를 눌러 지점·노선·부대사업 열기
- 비행기 화면의 🪑로 좌석 배치·기내식, ✈️ 타 보기로 운항 중인 비행기에 타서 3D로 따라가기
- 노선 창의 ‘등급별 운임’ 카드(💡 추천 운임)
- 설정에서 사업 모델(풀서비스·저가항공·화물 전문)
- 숫자키 1~7로 화면 바꾸기(5 인사), 경영 비서의 ‘적용’
- Enter로 이번 달 마치기, ⏩ 분기 끝까지 맡기기
- 오른쪽 위 ❓를 누르면 놀이 방법을 다시 볼 수 있어요.
- 하던 게임은 자동 저장돼서 창을 닫았다 열어도 이어서 할 수 있어요.
  (같은 브라우저, 같은 폴더 위치에서 열었을 때)
